🧰 WinUtil (Chris Titus Tech)

Utilitário de código aberto para instalar programas em lote, aplicar ajustes de desempenho e privacidade, corrigir problemas e configurar atualizações. Baixa sempre a versão mais recente do site oficial.

O Windows vai pedir permissão de administrador.
🔄 Atualização forçada do Windows (seu script)
  • Instala todas as atualizações (Windows Update + Microsoft Update) usando o módulo PSWindowsUpdate.
  • Reinicia sozinho quando necessário e continua depois do login, até não sobrar nada (máx. 15 rodadas).
  • Windows 10: trava na versão 22H2 e ignora o upgrade para o Windows 11. Windows 11: instala tudo normalmente.
  • No fim, limpa o cache de atualizações (downloads e Otimização de Entrega).

⚠ Salve seus trabalhos antes: o PC reinicia automaticamente (30 s de aviso — para cancelar, rode shutdown /a).
