Como usar os comandos
  1. No PC que você quer configurar, abra o PowerShell como administrador: Win + X → Terminal (Admin) ou Windows PowerShell (Admin).
  2. Cole o comando (botão direito ou Ctrl + V) e aperte Enter.

irm (Invoke-RestMethod) baixa o script do endereço indicado e iex (Invoke-Expression) o executa. Rode apenas comandos de fontes em que você confia.

🧰 WinUtil (Chris Titus Tech)

Utilitário de código aberto com interface gráfica: instala programas em lote, aplica ajustes de desempenho e privacidade, corrige problemas comuns e configura o Windows Update. O comando sempre baixa a versão mais recente do site oficial.

🔄 Atualização forçada do Windows (seu script)
  • Instala todas as atualizações (Windows Update + Microsoft Update) com o módulo PSWindowsUpdate.
  • Reinicia sozinho quando precisa e continua após o login, até não sobrar nada (máx. 15 rodadas).
  • Windows 10: fixa na versão 22H2 e não faz o upgrade para o 11. Windows 11: instala tudo normalmente.
  • No fim, limpa o cache de atualizações. Log em C:\ProgramData\WinUpdateHelper\update-log.txt.

⚠ Salve seus trabalhos antes: o PC reinicia automaticamente (30 s de aviso — para cancelar, rode shutdown /a).
